# 人是狐 1.21.1（NeoForge）移植笔记

本文件记录 `TLM_playermaid-1.20.1`（Forge）→ `TLM_playermaid-1.21.1`（NeoForge）移植过程中的
API 变化、踩过的坑与待办。所有签名均以本机 artifacts 核实过，来源：

- MC 1.21.1 反编译源码：`neoforge\build\moddev\artifacts\neoforge-21.1.219-minecraft-sources.jar`
- NeoForge 1.21.1 源码：`net.neoforged:neoforge:21.1.219:sources`
- 车万女仆 1.21.1 源码（同作者同类工程，写法参照）：`E:\Mod\TouhouLittleMaid-1.21`
- `javap -cp neoforge-21.1.219-minecraft-merged.jar <类>`

## 二、Forge → NeoForge 1.21.1 映射表（本项目实际用到的）

### 包与基类
| Forge 1.20.1 | NeoForge 1.21.1 |
|---|---|
| `net.minecraftforge.eventbus.api.*` | `net.neoforged.bus.api.*` |
| `@Mod.EventBusSubscriber(bus = ...Bus.FORGE)` | `@EventBusSubscriber(bus = EventBusSubscriber.Bus.GAME)`（GAME 是默认值） |
| `net.minecraftforge.common.MinecraftForge.EVENT_BUS` | `net.neoforged.neoforge.common.NeoForge.EVENT_BUS` |
| `net.minecraftforge.items.*` | `net.neoforged.neoforge.items.*` |
| `net.minecraftforge.registries.RegistryObject` | `net.neoforged.neoforge.registries.DeferredHolder` / `DeferredItem` |
| `net.minecraftforge.registries.ForgeRegistries.ITEMS` | `net.minecraft.core.registries.BuiltInRegistries.ITEM`（取值 `get()`，不是 `getValue()`） |
| `IForgeMenuType.create` | `IMenuTypeExtension.create` |
| `NetworkHooks.openScreen(player, provider, bufWriter)` | `player.openMenu(provider, bufWriter)` |
| `DistExecutor.unsafeRunWhenOn(Dist.CLIENT, ...)` | **NeoForge 已删除 DistExecutor**；改 `FMLEnvironment.dist == Dist.CLIENT` 判断后直调（`net.neoforged.fml.loading.FMLEnvironment`） |

### 事件
| 1.20.1 | 1.21.1 |
|---|---|
| `LivingHurtEvent` | `LivingIncomingDamageEvent`（`getAmount/setAmount`，`ICancellableEvent`） |
| `LivingAttackEvent` | **已并入 `LivingIncomingDamageEvent`**（同一个事件）——两个处理器必须定序：抵挡用 `HIGHEST`、改伤害用 `HIGH` 并检查 `event.isCanceled()` |
| `TickEvent.PlayerTickEvent`（含 `phase`） | `PlayerTickEvent.Post`（`net.neoforged.neoforge.event.tick`），`event.getEntity()` |
| `TickEvent.ServerTickEvent` | `ServerTickEvent.Post` |
| `PlayerEvent.player` 字段 | `event.getEntity()`（字段已私有） |
| `MobEffectEvent.Applicable.setResult(Event.Result.DENY)` | `setResult(MobEffectEvent.Applicable.Result.DO_NOT_APPLY)` |
| `RenderNameTagEvent.getResult()/setResult(Event.Result)` | `canRender()/setCanRender(TriState)`（`net.neoforged.neoforge.common.util.TriState`） |

### 网络
`SimpleChannel` 整层不可用，改为载荷式：
```java
public record XxxPacket(...) implements CustomPacketPayload {
    public static final CustomPacketPayload.Type<XxxPacket> TYPE =
            new CustomPacketPayload.Type<>(ResourceLocation.fromNamespaceAndPath(MOD_ID, "xxx"));
    public static final StreamCodec<FriendlyByteBuf, XxxPacket> STREAM_CODEC =
            StreamCodec.of((buf, p) -> p.write(buf), XxxPacket::read);
    @Override public CustomPacketPayload.Type<? extends CustomPacketPayload> type() { return TYPE; }  // 必须实现
    public static void handle(XxxPacket p, IPayloadContext ctx) { ctx.enqueueWork(() -> {...}); }
}
```
注册：`modEventBus.addListener(event -> event.registrar(版本).playToServer(TYPE, STREAM_CODEC, handle))`，
`RegisterPayloadHandlersEvent` 挂在 **mod 事件总线**。
发送：`PacketDistributor.sendToServer(p)` / `sendToPlayer(player, p)` / `sendToPlayersTrackingEntityAndSelf(entity, p)`。

## 三、TLM 1.21.1 的 API 情况

结论：**包名零变动、方法签名几乎逐字相同**。已核实 16 项（`IMaidBauble`、`EntityMaid`、
`BaubleManager`、`BaubleItemHandler`、`InitItems.SMART_SLAB_EMPTY`、`MaidAfterEatEvent`、`IMaidTask`、
`TaskManager`、`MaidTabButton`/`MaidSideTabButton`/`TaskButton`/`BaubleButton`、`ParseI18n`、
`CuriosCompat`/`CuriosButton`、`MaidMainContainer`/`BaubleContainer` 槽位坐标、6 张 GUI 贴图路径、
全部语言键）。仅两处需要注意：

1. `BaubleManager.BAUBLES` 的键类型从 `RegistryObject<Item>` 变成 `DeferredHolder<Item,Item>`，且两版都是
   private。本项目的「饰品绑定覆盖」因此改为**遍历现有条目、按键取出的物品注册 id 换值**（原键保留），
   比 1.20.1 版按 id 新建键更稳。
2. `TouhouImageButton` / `TouhouStateSwitchButton` 是 TLM 为保留旧贴图坐标 API 而新增的类，
   playermaid 的界面直接换用它们（playermaid 的 GUI 本就是 TLM 界面的复刻）。

## 四、行为基准：用 1.9.2，不用 1.21 那份 1.8.3.1

`E:\Mod\Touhou-Little-Maid-Spell-1.21`（1.8.3.1-neoforge）比 `E:\Mod\Touhou-Little-Maid-Spell-main`（1.9.2）**旧**，
且它的 NeoForge 改写引入了三处真实行为回退，**不要照抄**：

| 饰品 | 1.8.3.1 的回退 |
|---|---|
| 混沌之书 | 处理器挂在 `LivingDamageEvent.Post`（不可取消），原伤害之外再补 n 段，**总伤害约翻倍** |
| 魂之书 | owner 保护退化成朴素计数，删掉了 `hasOwnerProtection` 与全部清理 |
| 破愈咒锋 | 换成强引用 `LivingEntity` 作键、去掉跨维度校验、计数可转负，**有内存泄漏** |
| 双心之链 | 把 `instanceof Player` 改成硬转，主人不是 Player 时 CCE |
| 梦云水晶 | 丢了 `isApplyingQueuedDamage()` 真伤重入守卫 |

本项目一律以 **1.9.2 的语义**为准，只从 1.8.3.1 借 NeoForge 的 API 形态。

## 五、编译查不出、需要运行期验证的点

1. **收容维度 JSON**：1.21.1 的 `monster_spawn_light_level` 要求 `IntProvider` 对象，
   不再接受裸整数（已修成 `{"type":"minecraft:uniform","min_inclusive":0,"max_inclusive":0}`）。
2. **mixins.json 的 refmap**：TLM 1.21.1 的发布 jar 里**没有** refmap 文件（只带 mixins.json），
   说明 NeoForge 1.21 运行期不需要 refmap；本项目保留该字段与 TLM 一致。
3. **Mixin 注入点**：7 个 mixin 均在 `"mixins"`/`"client"` 列表中，且 `injectors.defaultRequire = 0`，
   注入点失效时只记警告不崩。仍需在 1.21.1 实机确认注入点是否存在
   （尤其 `ItemStackFoxTooltipMixin`、`PlayerNameTagMixin`、`PlayerHaloRenderMixin`）。
4. **软依赖缺失路径**：Jade / Curios 不在场时相关 Mixin 与插件应自动跳过（未实机验证）。
5. **专用服务器**：主类只引用 `FoxMaidMenus`/`NetworkInit`/`FoxMaidManager`/`FoxMaidInteractHandler`，
   无客户端类；客户端类（5 个 screen、halo 渲染器、tooltip 组件、2 个 client mixin）
   只被客户端上下文引用，且 2 个包类的客户端调用已用 `FMLEnvironment.dist` 门控。
